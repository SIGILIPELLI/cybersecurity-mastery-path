# Level 1 · Entry <span class="level-badge">Foundations</span>

Goal: understand the core concepts of cybersecurity — the CIA triad,
networking, OS security, cryptography, access control and the OWASP Top 10 —
and get a real home lab running with the tools the rest of this program
builds on.

## Modules

1. [What Is Cybersecurity?](01-what-is-cybersecurity.md)
2. [Networking Fundamentals for Security](02-networking-fundamentals.md)
3. [Operating System Security Basics](03-os-security-basics.md)
4. [Cryptography Fundamentals](04-cryptography-fundamentals.md)
5. [Authentication & Access Control](05-authentication-access-control.md)
6. [Common Web Vulnerabilities — OWASP Top 10 Overview](06-owasp-top-10-overview.md)
7. [Malware & Social Engineering Basics](07-malware-social-engineering.md)
8. [Security Tools Setup](08-security-tools-setup.md)
9. [Incident Response Basics](09-incident-response-basics.md)
10. [Project — Home Lab Security Assessment](10-project-home-lab-assessment.md)

By the end of this level you'll understand the fundamental vocabulary and
models of the field, have a working home lab (VMs, nmap, Wireshark), have
built and defensively tested a deliberately vulnerable local web app, and have
produced a real security assessment of your own lab environment.

!!! warning "Scope and authorization"
    Every hands-on exercise in this program targets **systems you own** — your
    own machine, your own local VMs, your own local web app. Scanning,
    exploiting, or testing any system you do not own or do not have explicit
    written authorization to test is illegal in most jurisdictions and is
    never in scope for this course.
